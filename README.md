## 📌 Featured Projects

### 🔹 LocalEmu (Open-Source AWS Emulator)
- Emulates **132 AWS services** locally — no account, no credentials, no internet
- Real behavior where it counts: Lambda runs in official AWS runtime images, EC2 instances are real containers on a real VPC with enforced security groups, RDS is an actual PostgreSQL/MySQL you can connect to
- Drop-in for the AWS CLI, boto3, Terraform and CDK · Apache-2.0 · **181★** on GitHub
- Built with **Python, Docker**

👉 https://www.localemu.cloud · [github.com/localemu/localemu](https://github.com/localemu/localemu)
